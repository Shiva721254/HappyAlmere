# Implemented HA-002-A data dictionary

Review candidate. Physical source of truth: embedded CatalogForward.sql and EF model.
All times are timestamptz. Initial timestamps are migration provenance, not recovered
creation history; future writers must deliberately maintain updated_at. No application
write workflow is introduced. UUIDs generated by Domain defaults are random v4;
reserved imported UUIDv8 mapping is documented in migration-policy.md.

| Table | Columns and constraints |
|---|---|
| catalog.cities | id UUID PK; legacy_id nullable unique int; name varchar(100); slug varchar(80) unique slug syntax; country_code varchar(2) uppercase; default_language varchar(10) language syntax; time_zone varchar(100), validated against PostgreSQL timezone catalog; is_active; created_at/updated_at |
| catalog.city_domains | id UUID PK; city_id restrictive FK; hostname varchar(253), lowercase normalized ASCII DNS/punycode syntax, unique; is_primary/is_active; at most one active primary per city; created_at |
| catalog.districts | id UUID PK; city_id FK; parent_id nullable same-city composite FK; name/slug varchar(100), unique city+slug; external_code varchar(100) nullable; district_type varchar(30); is_active; timestamps; self-parent/cycles rejected |
| catalog.locations | id UUID PK; city_id FK; optional district_id same-city composite FK; street varchar(200); house_number numeric string varchar(20); suffix varchar(20) nullable; postal_code varchar(20); country_code varchar(2); optional bag_identifier varchar(16); latitude/longitude numeric(9,6), paired and range checked; timestamps |
| catalog.categories | id UUID PK; legacy_id nullable unique int; optional parent_id FK, self-parent/cycles rejected; slug varchar(30) unique; name varchar(100) retained Dutch fallback; category_type varchar(30); display_order int; is_active; timestamps |
| catalog.category_translations | category_id FK + language_code varchar(10) composite PK; name varchar(100); description varchar(2000) nullable; initial nl name copied verbatim |
| discovery.discovery_entries | id UUID PK; nullable unique legacy_id; city_id/category_id restrictive FKs; retained nullable legacy_city_id/legacy_category_id compatibility metadata; slug varchar(120) unique per city; title varchar(200) nonblank; description varchar(2000); district varchar(100) exact legacy display text; icon varchar(16); is_published |

No address uniqueness is imposed: legitimate co-location is possible. No authoritative
address/BAG/geography data is inferred. The public UI preserves its existing Dutch
category behavior; stored translations do not claim a new multilingual UI. Unknown
cities require explicit country/language/timezone settings. Inactive cities/categories
and unpublished entries are excluded from discovery.

FK lookup, slug uniqueness, and city/publication/category/order indexes support current
queries. The partial expression page-order index serves published discovery; measured
plans and scope are recorded with implementation evidence. Legacy metadata/indexes are
retained through the compatibility phase; removal requires a later reviewed migration.
