# HA-005-A — PostgreSQL 18 Dutch Full-Text Search

## Scope
Upgrades public discovery search in `discovery.discovery_entries` from substring-only `ILIKE` matching to PostgreSQL 18 Dutch Full-Text Search (`dutch` snowball stemmer) with weighted relevance ranking and a GIN index, while preserving:
- Compound-word Dutch substring matching (e.g., `familie` matching `familiedag`).
- Least-privilege runtime database access (`happy_app` remains strictly `SELECT`-only).
- Deterministic keyset cursor pagination in `PostgresDiscoveryRepository.FindPageAsync`.
- Full forward-migration, fault-injection rollback, and restricted `happy_backup` dump/restore parity.

## Physical Schema Contract
Migration: `20261123113902_DutchFullTextSearch` (appended after immutable `InitialDiscovery`, `CatalogForward`, and `SupportedRegions`).

- **Generated column:** `discovery.discovery_entries.search_vector` (`tsvector`, `GENERATED ALWAYS AS (...) STORED`)
  - Weight `A` (`1.0`): `title`
  - Weight `B` (`0.4`): `district`
  - Weight `C` (`0.2`): `description`
  - Expression: `setweight(to_tsvector('dutch', coalesce(title, '')), 'A') || setweight(to_tsvector('dutch', coalesce(district, '')), 'B') || setweight(to_tsvector('dutch', coalesce(description, '')), 'C')`
- **Index:** `ix_discovery_entries_search_vector` (`USING gin (search_vector)`).
- **Domain isolation:** Mapped as a strongly-typed EF Core shadow property (`NpgsqlTsVector?`) in `HappyCityDbContext` so `HappyCity.Domain` remains free of database/provider dependencies.

## Query & Security Semantics
- **Parser:** Uses `plainto_tsquery('dutch', @q)` rather than `to_tsquery` or `websearch_to_tsquery` so untrusted user input can never raise syntax errors or inject boolean negation/union operators (`-term` negation scans or `OR` broadening).
- **Hybrid match predicate:** Matches when `search_vector @@ plainto_tsquery('dutch', @q)` OR escaped literal `ILIKE` matches `title || ' ' || description || ' ' || district` (handling Dutch compound words such as `familiedag`, `winkelaanbiedingen`).
- **Relevance ranking (`FindAsync`):** When `filter.Query` is present, orders by `ts_rank_cd(search_vector, plainto_tsquery('dutch', @q)) DESC` with deterministic tie-breaking `(legacy_id IS NULL), legacy_id, id`. Title hits (`A`) rank above district (`B`), description (`C`), and substring-only fallback (`0`).
- **Keyset pagination (`FindPageAsync`):** Preserves `((legacy_id IS NULL), COALESCE(legacy_id, 0), id)` cursor ordering with filter-bound cursor verification.
