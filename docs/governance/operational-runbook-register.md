PROD-A08/A09; all20 canonical RUN identifiers preserved. These bounded procedure contracts are NOT rehearsed runbooks or authorization to act. Each owner role needs a named primary/backup appointment, escalation contact, written target/time/scope authority and evidence-retention location before use. Common evidence per run: trigger and time, exact artifact/target, authorized operator/approval, commands and exit results, positive control plus intended denial, failure/skip/rollback state, sanitized digest/location, independent review and return-to-service decision. Escalate safety, scope, credential, integrity or recovery uncertainty immediately to commander/owner; stop rather than improvise. Retain original failures, protected customer evidence separately, never in Git.
